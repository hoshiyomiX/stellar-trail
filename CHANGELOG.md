## v5.5.1 — 2026-11-01 · harness-hooks §9b: refresh-if-byte-identical seeding — the Task 49 audit gap closed (owner order — Task 50, ref #49)

**Why — the Task 49 AGENTS.md criticality audit found a real version-drift class in bootstrap §9b:** the module seeded CLAUDE.md/AGENTS.md at the project root create-if-absent ONLY — an unmodified root seed was never refreshed when the template changed across releases, while the --status label "SEEDED (managed)" overstated management (a "managed" seed that no longer tracked its template). Risk was LOW today (the template is instruction-level, version-agnostic, and byte-stable since 2026-10-08) but the class was real: any future template improvement would silently strand every existing install on the old bytes. The owner ordered the fix executed ("eksekusi perbaikan §9b").

**What shipped:**

- **seed-hashes.txt registry (assets/harness-hooks/, NEW):** one sha256 per template version ever shipped, one line per file. Runtime semantics: a root CLAUDE.md/AGENTS.md whose hash is registered (but differs from the current template) is an UNMODIFIED seed of an older release — bootstrap refreshes it to current; a hash listed nowhere is a user-edited file — never touched. The registry rides the checksum manifest like every payload file; the maintenance rule (a release that changes a template appends the new hash in the same release) lives in its header — the audit's "release-checklist line" option folded in.
- **bootstrap-sandbox.sh §9b (module paths):** module-on now has four states (seed · current-never-rewritten · REFRESH-registered-old-seed · keep-user-file) · --without-harness-hooks removes OLD-version unmodified seeds too (registry-listed), not only current-template-identical ones · the --status display gains a third state (STALE SEED — refresh on next --ensure), making "managed" mean actually-tracked · header + module-list comments updated.
- **bootstrap-sandbox.sh (boot chain + helper):** the dev.sh step-7 heredoc carries the same refresh inline (project-root files are not in the packer preserve list) · new `seed_known` helper (awk registry lookup; registry absent = pre-v5.5.1 install = safe old behavior).
- **SKILL.md §6 + skill-card.md + environment-resilience.md:** the hooks semantics text updated everywhere it is described — create-if-absent + refresh-if-byte-identical, registry-tracked, user-edited files never touched.
